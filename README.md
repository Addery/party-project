# 智慧党建管理平台

## 项目简介
智慧党建管理平台是一个专为党组织设计的综合管理系统，旨在提升党建工作的信息化、数字化水平。平台包含前端Vue应用和后端Java服务，提供了丰富的功能模块，如党员管理、活动管理、学习资源、新闻公告、就业服务等。

## 项目结构

```
partyproject/v3/
├── back/             # 后端Java代码
│   ├── src/          # 源代码
│   ├── docs/         # 后端文档
│   ├── sql/          # 数据库脚本
│   ├── scripts/      # 工具脚本
│   └── pom.xml       # Maven配置文件
├── front/            # 前端Vue代码
│   ├── src/          # 源代码
│   ├── api/          # 前端API文档
│   ├── docs/         # 前端文档
│   └── package.json  # NPM配置文件
└── README.md         # 项目说明文件
```

## 技术栈

### 后端技术
- Java 11+
- Spring Boot 2.x
- Spring Security
- JPA/Hibernate
- MySQL
- JWT 认证

### 前端技术
- Vue 3
- Vite
- Vue Router
- Pinia (状态管理)
- Axios (HTTP客户端)

## 功能模块

### 后端功能
- **用户认证**：登录、注册、JWT token管理
- **活动管理**：活动发布、报名、管理
- **学习资源**：资源上传、分类、查询
- **新闻公告**：新闻发布、分类、查询
- **就业服务**：就业信息、政策、指导
- **支部管理**：支部信息、党员管理
- **用户画像**：党员行为分析、画像生成

### 前端功能
- **首页**：活动推荐、新闻公告、学习资源
- **活动中心**：活动列表、活动详情、报名
- **学习中心**：学习资源列表、资源详情
- **新闻中心**：新闻列表、新闻详情
- **就业服务**：就业信息、政策、指导
- **个人中心**：个人信息、学习记录、活动记录
- **后台管理**：用户管理、活动管理、新闻管理等

## 快速开始

### 后端启动
1. 确保安装了Java 11+和Maven
2. 配置数据库连接（修改`back/src/main/resources/application.yaml`）
3. 执行数据库脚本（`back/sql/database.sql`）
4. 启动后端服务：
   ```bash
   cd back
   mvn spring-boot:run
   ```

### 前端启动
1. 确保安装了Node.js 14+
2. 安装依赖：
   ```bash
   cd front
   npm install
   ```
3. 启动前端服务：
   ```bash
   npm run dev
   ```
